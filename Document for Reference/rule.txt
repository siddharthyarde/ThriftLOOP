## Naming Rules
- Folders: kebab-case only, except standard framework folders like `src`.
- React components/pages: PascalCase, for example `ListingCard.jsx`, `CreateListing.jsx`.
- React hooks: camelCase starting with `use`, for example `useAuth.js`.
- Context files: PascalCase with `Context`, for example `AuthContext.jsx`.
- Backend routes: plural lowercase domain names, for example `listings.js`, `transactions.js`.
- Controllers: singular domain + `Controller`, for example `listingController.js`.
- Middleware: camelCase purpose names, for example `authGuard.js`, `errorHandler.js`.
- Services: lowercase provider/domain names, for example `supabase.js`, `razorpay.js`.
- Utilities: camelCase action/domain names, for example `qrGenerator.js`, `seedData.js`.
- Environment variables: uppercase snake case.
- Git branches: kebab-case, for example `setup/project-scaffold` or `feature/auth-module`.
- Commit messages: conventional commits, for example `feat: add auth routes`.
